# Research archive

This directory preserves development history that is not part of the promoted
model contract.

- [Model 01 archive](m01/model_audit.md)
- [Model 02 archive](m02/README.md)

Archived documents describe diagnostics, sensitivities, attribution work, and
alternative allocation experiments. They are retained for provenance only.
None replaces the promoted inference or allocation baseline documented in the
main [Model 01](../models/m01_deterministic_composite/README.md) or
[Model 02](../models/m02_soft_composite/README.md) model card.

Machine-readable configurations, manifests, and published outputs remain the
authoritative record for each experiment.
